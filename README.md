# Portfolio / CV

Sitio personal tipo portfolio y currículo.

## Qué usa

- **HTML**: Para la estructura del contenido.
- **CSS**: Para el estilo y diseño visual.
- **JavaScript**: Para interactividad y lógica de front-end, incluyendo la gestión de idiomas.
- **Tailwind CSS**: Framework CSS para un diseño rápido y responsivo.
- **i18n**: Maneja las versiones en español e inglés. El contenido de las traducciones se encuentra en `assets/js/i18n.js`.
- **Google Fonts**: Para la tipografía `Inter`.
- **SEO y metadatos**: Incluye Open Graph, Twitter Cards y datos estructurados JSON-LD.
- **Analítica Básica**: Puede incluir un sistema modular de eventos para trackear el uso, implementado a través de JavaScript.

## Estructura

- `index.html`: La página principal del sitio.
- `assets/`: Contiene todos los recursos estáticos.
  - `assets/css/style.css`: Estilos principales de la aplicación.
  - `assets/js/script.js`: Lógica principal de JavaScript.
  - `assets/js/i18n.js`: Lógica para la internacionalización.
  - `assets/foto.jpg`, `assets/procontacto.jpg`: Imágenes del proyecto.

## Tracking y Analítica

El proyecto puede incluir un sistema de analíticas modular implementado en JavaScript para el seguimiento básico de la interacción del usuario.

## Comandos básicos

Para visualizar el sitio, simplemente abre `index.html` en tu navegador web. No se requieren comandos de build o desarrollo para este proyecto estático.

## Qué hace cada tecnología

- **HTML**: Organiza la estructura del contenido web.
- **CSS**: Define la presentación visual del sitio.
- **JavaScript**: Añade interactividad y permite la carga dinámica de contenido, como la gestión de idiomas.
- **i18n (Internacionalización)**: Permite servir el contenido en dos idiomas sin duplicar toda la base del sitio.

## Notas

El sitio está pensado para publicarse en GitHub Pages u otro servicio de hosting estático.

El modo visual puede incluir tema claro/oscuro y ajustes para impresión, implementados con CSS y JavaScript.
